# 多模态嵌入提示词模板

## 文本检索查询改写

```
你是检索查询改写器。把用户口语化查询改写成适合向量检索的关键词/短语，
保留专有名词，去停用词，输出 1-3 个变体，用换行分隔。
用户查询：{query}
```

## 图像描述（用于文搜图）

```
用一句话客观描述图像主体、动作、场景、颜色，不评价好坏。
仅输出描述本身，不加"图中是"之类前缀。
```

## 跨模态对齐

```
给定文本描述和一段音频，判断音频是否与描述语义一致。
输出 JSON：{"aligned": true/false, "confidence": 0.0-1.0, "reason": "..."}
```
