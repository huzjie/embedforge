# Matryoshka Representation Learning（嵌套维度学习）

## 问题

传统嵌入模型训练时固定一个维度（如 768）。你要 128 维做省内存的近似检索，就必须重新训练一个小模型。成本翻倍、维护两套。

## 思路

**MRL 让一个模型同时服务任意维度**：训练时对多个嵌套宽度（如 8/16/32/64/.../768）各算一次对比损失并求和。因为损失是嵌套的，向量的前 k 维本身就构成一个合格的 k 维嵌入。

```
loss_mrl = sum over widths w of  contrastive_loss(truncate(emb, w), truncate(doc_emb, w))
```

推理时直接切片 `emb[:w]` 即可，无需重训。

## 可复用要点

1. **宽度必须是嵌套的**（8/16/32/64/...），不是任意的，否则"前缀即有效"的性质不成立。
2. **全维度一定要在宽度列表里**（否则模型永远不被约束到完整 768 维）。
3. 截断后要**重新 L2 归一化**——截断会改变模长，归一化后余弦才可比。
4. 实测口径用"**排序一致性**"：`width=w` 的 top-k 邻居与全维 top-k 邻居的重合度，随 w 增大单调趋 1。

本项目实现见 `projection/matryoshka.py` 与 `bench/matryoshka.py`。
